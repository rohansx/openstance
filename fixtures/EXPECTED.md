# Fixture contract (Phase 1)

Generated by `cargo run -p openstance-fixtures --bin gen-fixtures`; do not edit by hand.
Every name, domain and phone number is fictional (`*.example`, `*.test`, `*.invalid`, `example.com`, `+1 201 555-01xx`).

**This is the contract the resolution stream must hit exactly (P1-CORE-12).** The numbers were derived by
walking every cast member through the rules in `docs/tech-spec/entity-resolution.md`; the reasoning for each
person is in the cast table below. Changing a fixture or a rule means updating this file deliberately.

## How to load

Import all five files into one graph **with `fixtures/config.toml`** (it sets the owner's `[me]` handles and
treats `gmail.test` / `googlemail.test` as Gmail domains and `mail.test` as freemail):

```sh
OPENSTANCE_CONFIG=fixtures/config.toml openstance import \
  fixtures/mbox/small.mbox fixtures/linkedin/Connections.csv fixtures/linkedin/messages.csv \
  fixtures/linkedin/Invitations.csv fixtures/vcf/contacts.vcf
```

Totals are independent of import order (incremental equals full rebuild).

## Formats exercised

- `linkedin/Connections.csv`: UTF-8 BOM, `Notes:` preamble, CRLF, empty `Email Address` for most rows, a quoted comma in `Position`, `Connected On` as `12 Mar 2024`.
- `linkedin/messages.csv`: vanity profile URLs, `DATE` as `2026-08-03 10:00:00 UTC`, multi-line quoted `CONTENT` (never read), `FOLDER` INBOX/SENT.
- `linkedin/Invitations.csv`: `Sent At` as `9/15/26, 10:00 AM`, INCOMING/OUTGOING, `Message` never read.
- `vcf/contacts.vcf`: vCard 2.1 (quoted-printable UTF-8), 3.0 and 4.0 (`tel:` URI), CRLF, folded lines (base64 PHOTO, folded EMAIL value), grouped `item1.EMAIL`, `ADR`, `REV`, `NOTE`/`CATEGORIES` ignored.
